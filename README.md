# 基于springboot+vue的校园失物招领管理系统带万字论文



## 一、介绍


语言: Java 数据库：MySQL 

技术栈：SpringBoot+MybatisPlus+Vue+Html

系统角色：管理员、用户

管理员：管理员：登录、基础数据管理、系统管理、留言板管理、失物信息管理、失物认领管理、寻物启事管理等功能

用户：登录、注册、留言板、公告信息、失物招领、失物认领、寻物启事、个人中心、我发布的失物信息、我的失物认领、我发布的寻物启事、寻物启事留言等功能
